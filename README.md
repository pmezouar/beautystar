## ✨ À propos du projet

**Beauty Star** est un site vitrine conçu pour **présenter les prestations** que le salon de beauté propose et **faciliter la prise de contact**.

Ce projet a été conçu dans le but de proposer un site vitrine moderne, intuitif et facilement maintenable.

---

## 🎯 Objectifs

* ✨ Valoriser les réalisations
* 📖 Présenter les prestations
* 📩 Simplifier la prise de contact avec l'institut


---

## 🧠 Approche technique

Ce projet a été développé avec une attention particulière portée à :

* 🔎 La navigation
* 📱 L’accessibilité et le responsive design
* 📈 L'évolution et la maintenabilité

---

## 🛠️ Stack technique

### Frontend

* HTML5
* CSS3
* JavaScript

### API

* Formspree (pour l'envoi sécurisé du formulaire de contact)


### Outils

* Git / GitHub
* VS Code
